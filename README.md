# Formulario de Cambio de Turno

Aplicación web para registrar solicitudes de cambio de turno mediante una interfaz clara, adaptable y orientada al uso operativo.

Proyecto inspirado en un caso real de digitalización de procesos operativos, adaptado con datos e información ficticios para portafolio.

## Objetivo

Digitalizar un proceso que normalmente podría gestionarse de forma manual, permitiendo capturar la información necesaria desde una interfaz web y aplicar validaciones antes del envío.

## Funcionalidades

- Captura de datos del colaborador que solicita el cambio.
- Selección de turno actual y turno propuesto.
- Selección de fecha del cambio.
- Campo de justificación / observaciones.
- Validación de campos obligatorios antes del envío.
- Confirmación visual al enviar la solicitud.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Estructura

- `index.html`: formulario principal.
- `estilos.css`: diseño visual.
- `script.js`: lógica, validaciones e interacción.
- `docs/capturas/`: espacio preparado para evidencias visuales del proyecto (usar solo datos ficticios).

## Qué demuestra este proyecto

- Digitalización de un proceso operativo.
- Construcción de formularios empresariales.
- Validación de información con JavaScript.
- Separación entre estructura, presentación y lógica.
- Diseño orientado a uso práctico.

## Estado

Proyecto funcional de práctica aplicada, con datos ficticios. No representa la configuración ni los datos de ningún cliente real. Para uso productivo se recomienda revisar integraciones, seguridad, manejo de datos y configuración de servicios externos.
