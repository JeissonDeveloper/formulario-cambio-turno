# Formulario de Cambio de Turno

Aplicación web para registrar solicitudes de cambio de turno mediante una interfaz clara, adaptable y orientada al uso operativo.

## Objetivo

Digitalizar un proceso que normalmente podría gestionarse de forma manual, permitiendo capturar la información necesaria desde una interfaz web y aplicar validaciones antes del envío.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Estructura

- `index.html`: formulario principal.
- `estilos.css`: diseño visual.
- `script.js`: lógica, validaciones e interacción.
- `logo-ramo.png`: recurso gráfico utilizado en la interfaz.

## Valor del proyecto

Este repositorio muestra experiencia construyendo formularios web para procesos empresariales, con separación de responsabilidades entre HTML, CSS y JavaScript.

## Estado

Proyecto funcional de práctica aplicada. Para uso productivo se recomienda revisar integraciones, seguridad, manejo de datos y configuración de servicios externos.
